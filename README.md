# odin-recipes
Create a recipes website for The Odin Project recipes curriculum 

Create a cook book style website that shows 3 recipes. These recipes are all linked to the main
index.html website. Each recipe has a link to the main page and has the following items in them:
- anchor tags with links to the pages in the website
- images with href's and alts
- ordered and unordered lists for Steps and Ingredients to make the recipe
